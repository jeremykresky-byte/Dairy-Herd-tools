=====================================================
HOW TO DEPLOY YOUR DAIRY HERD MANAGER TO FIREBASE
=====================================================

This will put your app on a real web address like:
https://wridair-farms-dairy-herd.web.app

Everyone on your team just goes to that URL and logs in.
No more opening files locally. Works on phones too.

ALL authenticated users can read and write data equally.
Anyone with a login can add/edit animals, health records,
breeding, milk, feed, financials, and vet requests.

=====================================================
ONE-TIME SETUP (5 minutes)
=====================================================

STEP 1: Install Node.js
  - Go to https://nodejs.org
  - Download and install the LTS version (the big green button)
  - Restart your computer after installing

STEP 2: Install Firebase Tools
  - Open Command Prompt (search "cmd" in Windows Start menu)
  - Type this command and press Enter:

    npm install -g firebase-tools

  - Wait for it to finish (takes about a minute)

STEP 3: Log in to Firebase
  - In the same Command Prompt, type:

    firebase login

  - A browser window will open
  - Sign in with the same Google account you used
    to create your Firebase project

=====================================================
DEPLOY (30 seconds)
=====================================================

STEP 4: Navigate to the deploy folder
  - In Command Prompt, type:

    cd "C:\Users\Jeremy\OneDrive\Dairy Herd Tools\firebase-deploy"

STEP 5: Deploy!
  - Type this command and press Enter:

    firebase deploy

  - This deploys BOTH the website AND the Firestore
    security rules that let all users edit data
  - Wait about 30 seconds
  - When it finishes, you'll see a URL like:
    https://wridair-farms-dairy-herd.web.app

  - That's it! Share that URL with your team.

=====================================================
ADDING TEAM MEMBERS
=====================================================

Each person just needs to:
1. Go to https://wridair-farms-dairy-herd.web.app
2. Click "Register" and create an account
3. They can immediately add and edit all data

Everyone shares the same database in real time.

=====================================================
UPDATING THE APP LATER
=====================================================

If you ever update the app:

1. Copy the new dairy-herd-manager.html into the
   firebase-deploy\public folder, renamed as index.html

2. Open Command Prompt and run:
   cd "C:\Users\Jeremy\OneDrive\Dairy Herd Tools\firebase-deploy"
   firebase deploy

That's it - the live site updates in about 30 seconds.

=====================================================
TROUBLESHOOTING
=====================================================

"firebase is not recognized"
  -> Restart Command Prompt after installing Node.js

"Error: No project active"
  -> Run: firebase use wridair-farms-dairy-herd

"Permission denied"
  -> Run: firebase login
  -> Make sure you sign in with the same Google account

"Deploy failed"
  -> Make sure you're in the firebase-deploy folder
  -> Make sure public/index.html exists

"Users can't save data"
  -> Make sure you deployed with: firebase deploy
     (this pushes both the site AND the Firestore rules)
  -> Check Firestore Rules in Firebase Console:
     https://console.firebase.google.com
     -> Your project -> Firestore -> Rules
     -> Should say: allow read, write: if request.auth != null;
